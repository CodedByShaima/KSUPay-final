# KSUPay - University Payment System

## Overview
A desktop payment system built for King Saud University to manage 
financial transactions on campus. Students can sign up, log in, 
and transfer money, while admins manage the entire system.

## Tools Used
- Python
- Tkinter (GUI)
- SQLite

## Features
- Student sign up and login with input validation
- Student wallet with money transfer between KSU entities
- Admin panel to:
  - Create wallets for students and KSU entities
  - Deposit monthly stipends to all students
  - Reset all KSU entity balances
  - Backup all data to CSV files
